# Visitor origin

- Store `ip_address` (max 45), ISO-2 `country`, and `user_agent` (max 191) on public enquiries and datasheet exports.
- Prefer CDN headers (`CF-Connecting-IP`, `CF-IPCountry`, CloudFront, and similar). Skip Cloudflare unknowns (`XX`, `T1`).
- For public IPs with no country header, look up `https://ipwho.is/{ip}` with a short timeout. Never look up private or reserved IPs. Do not add a GeoIP Composer package.
- Record public CMS page views and product-detail views (`?id=` Airtable id) in `page_visits` with `ip_address` (max 45), ISO-2 `country`, and `user_agent` (max 191). Prefer CDN country headers; if missing, look up `https://ipwho.is/{ip}` with a short timeout and cache the result for a day. Never look up private or reserved IPs. Skip staff/admin sessions, bots, `/products`, `/trade-login`, and 404s. Product-detail visits feed Top Products only, not Most Visited Pages.
- Metric SQL must `GROUP BY` real columns (not only `COALESCE`/`MONTH(...)` expressions). Host MySQL/MariaDB `ONLY_FULL_GROUP_BY` rejects grouping by those expressions even when they match the `SELECT` list.
- Show country, IP, and device on enquiry dialog facts (always, with — when unknown). On datasheet exports, show those fields in the info modal, not as an Origin column.
- Dashboard home is an **Overview**: date under the title, then content shortcut cards (Projects, Products, Pages, Sections, Staff), then **Audience Engagement Metrics** (year in a badge), then **Most Visited Pages** and **Visitors by Country** (from `page_visits`, all kinds), then **Top Products** (full-width ranked card: page views + datasheet exports + unique quote SKUs, equal weight; each row shows rank, thumbnail, name, SKU, and a preview icon to the public product page — no percentage or bar), then **Enquiries Metrics** and **Datasheet Metrics**, then pending Quote / Product / Contact boards that use the same card header as the metric cards (icon mark and green wash). Origin cards use a Country/Device switch and a horizontal percentage bar chart of the top 10 groups (no total). Visit/country rank cards use the same bars without the switch. Those four cards use a share layout (color pip, percent pill, inset bars), not the Top Products row style. Top Products uses numbered ranks in a stacked full-width list with the first product highlighted. Rank chips, a left accent, and the lead-row tint use the same 10 greens as the share-card bars (`DashboardMetricsService::COLORS`), not one muted chip. Engagement is a yearly grouped column chart of monthly enquiry and datasheet-export totals for the current year, with a y-axis scale and grid. Enquiry counts only include types the signed-in user can manage. Unknown country or device groups as Unknown. Visit pages/countries require pages, products, datasheets, or enquiries access. Top Products requires products, datasheets, or quote enquiries access. Do not add a Datasheet shortcut card on home.
